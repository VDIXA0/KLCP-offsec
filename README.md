# KLCP — Kali Linux Certified Professional

## About This Repository

This repository documents my learning journey through **Kali Linux Revealed (PEN-103)** by **OffSec (Offensive Security)**, which is the official training path associated with the **Kali Linux Certified Professional (KLCP)** certification.

The purpose of this repository is to document the knowledge, practical exercises, labs, notes, and concepts I study throughout the course while building a strong foundation in **Linux, Kali Linux, and cybersecurity**.

This is not intended to represent an earned certification unless the KLCP examination has been successfully completed. Instead, it serves as a record of my **hands-on learning and continuous development**.

---

## What is KLCP?

**KLCP — Kali Linux Certified Professional** is an OffSec certification focused on demonstrating knowledge and proficiency with **Kali Linux**.

Kali Linux is a Debian-based Linux distribution widely used in cybersecurity, penetration testing, digital forensics, security research, and related security disciplines.

The KLCP learning path provides a structured way to develop a deeper understanding of Kali Linux and the Linux environment that many cybersecurity tools and workflows rely on.

---

## What is PEN-103?

**PEN-103: Kali Linux Revealed** is the OffSec course associated with the KLCP certification path.

The course focuses on developing a practical understanding of:

* Linux fundamentals
* Kali Linux
* The Linux filesystem
* System administration concepts
* Package management
* System configuration
* Users and permissions
* Linux security concepts
* Networking fundamentals
* Kali Linux configuration and usage
* Practical troubleshooting
* Working effectively in a Linux environment

The goal is not simply to memorize information, but to understand how Linux and Kali Linux work and how that knowledge can be applied in cybersecurity.
